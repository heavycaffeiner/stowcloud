# Release v0.14.1

This release refines long file and folder name truncation.

## File browser

Long names in list and grid views now keep both their beginning and final eight graphemes visible. The middle contracts to an ellipsis when space is limited, preserving recognizable prefixes together with extensions and distinguishing suffixes.

Rows retain their fixed height on narrow screens and do not overlap adjacent content.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.14.1`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.14.1`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
