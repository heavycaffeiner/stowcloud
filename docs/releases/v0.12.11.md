# Release v0.12.11

The search panel says what it is filtering by without being opened.

## Folders no longer get a sentence about extensions

Choosing folders used to leave the file-type rows behind a line reading
"folders carry no extension, so file types do not apply". The controls are
simply gone while folders are the target, which is what the sentence was
there to explain.

## The controls moved out of the menu

Everything, Files and Folders sit beside the query as three buttons, so the
target is one click away and visible without opening anything. The menu that
remains holds the file-type groups, and each group picked shows as a chip
that can be dropped again. A summary line used to stand in for this, and it
listed what a group expands to: twelve extensions for "images".

The sort control was a select box on a row of its own; it is now a text
button beside the count, which gave the results list that row back. The
count of files and folders moved up next to it from a footer under the list.

## Rows read in two lines

The name has the row's width and the folder sits under it. Side by side, a
long path took the space the name needed and both ended in an ellipsis.

## Verification

Driven in a browser against a running engine: choosing folders drops the
extension controls, picking a group adds a chip that removes on click, the
sort menu reorders, a typed extension that matches nothing names itself in
the empty state, and the phone layout keeps the name, the folder and one
number per row.
