# Release v0.13.1

The navigation and settings interface is shorter, clearer and usable on narrow screens.

## Mobile navigation keeps the main destinations visible

The bottom bar now holds Files, Recent, Trash and Menu. Links, folder switching, personal settings and administrator settings remain one tap away inside Menu without squeezing five labels across a phone.

The active Menu state also covers Links, Settings and Admin, so the bar continues to show where the current screen belongs.

## Folder switching is direct

The old "Browse folders" control is now "Switch folder" in English and "폴더 전환" in Korean. On mobile it opens a full-width folder surface above the bottom navigation instead of a narrow drawer. On desktop the folder list is shown directly without a redundant expandable row.

The file browser header uses less vertical space on compact screens and removes secondary view status from the narrow layout.

## Settings labels and tabs fit their content

Personal settings now use Account, Security, Connections and Preferences. Administrator settings use People, Shares, Storage, Server and Logs. Korean labels were shortened to the matching task names.

Both settings screens use content-sized, horizontally scrollable tabs instead of compressing translated labels. Card spacing and page widths are aligned across mobile and desktop.

Server settings shortcuts are now a compact horizontal strip for SMB, Search, Network, Transfers, Security and Storage paths.

## Verification

The changed file browser, folder switcher, personal settings, administrator settings and server settings were exercised in Chromium at 390 by 844 and 1440 by 900. The Svelte type check completed with zero errors, localization validation reported 1,224 matching keys across two locales, and the production build completed successfully.
