# Release v0.6.0

This release refactors SMB deployment, adds runtime configuration consumers, implements server self-restart, enforces the database size guard, provisions user home directories automatically, and delivers the frontend UX redesign specification alongside its first increment.

## What changed

**The SMB sidecar runs as a container daemon.** The bare-metal host deployment is replaced by a containerized daemon communicating over a shared socket. File sharing switches apply without requiring a container restart.

**Server restart without container recreation.** The server re-executes itself on an administrative restart request, preserving port bindings and file descriptors.

**Settings changes apply live.** Administrative configuration saves now reach active runtime consumers immediately. The server rebinds listening sockets dynamically when host or port settings change.

**Database size guard enforcement.** The server enforces database size limits and minimum free disk space bounds, rejecting new writes when thresholds are reached.

**Automatic user home folders.** User home directories are provisioned automatically on first login from a configurable template directory.

**Folder size estimation and selection archives.** The file browser queries recursive folder sizes via dedicated probes, and downloading a selection streams an uncompressed or compressed zip archive directly without buffering on the server.

**Frontend UX specification and initial increment.**
- Tree navigation auto-expands ancestor directories on navigation, increases row touch targets to 40px, applies an M3 full-pill shape, and highlights active folders with primary brand color.
- Settings is reorganized into Material 3 container cards with responsive mobile padding (16px below 600px), a user initial avatar, and separated username display.
- Every user setting strictly maps to an authenticated v1 API endpoint, preserving per-tab dynamic import boundaries and URL hash deep-link contracts.
- A comprehensive UX audit and Google Drive blueprint covering future increments (top app bar, unified drawer, sticky table headers) is documented under `docs/frontend-ux-audit.md`.

## Upgrading

Pull the updated container images:

```
ghcr.io/heavycaffeiner/stowcloud:0.6.0
ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.6.0
```

Compose stacks using `:stable` or `:latest` can pull and restart directly.
