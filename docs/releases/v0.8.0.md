# Release v0.8.0

This release resolves the security, concurrency, and reliability findings identified in the 2026-09-05 audit.

## Security fixes

- **Origin cross-site scripting defense**: File streaming enforces attachment disposition on browser-executable media types (`text/html`, `application/xhtml+xml`, `image/svg+xml`, JavaScript, and XML variants) when served inline, and attaches a sandboxing Content-Security-Policy header. Direct streaming routes enforce isolation to the configured content host.
- **Public link rate limiting and Argon2 permit protection**: Link unlock requests enforce a sliding-window attempt budget (10 attempts per 5 minutes per client IP and link). Subsequent visits to password-protected links verify an HMAC ticket bound to the stored password hash instead of re-running memory-hard Argon2id hashing on each request.
- **SSO password deactivation**: Linking an external OpenID Connect provider clears local password credentials, and local password logins are rejected with decoy hashing when an active OIDC link exists.
- **Trusted proxy validation**: Configuring `0.0.0.0/0` as a trusted proxy is promoted to a hard validation rejection to prevent client address spoofing.
- **Session revocation on password change**: Changing an account password invalidates all active sessions for that account.

## Concurrency and access control

- **Upload engine chunk synchronization**: Concurrent writes targeting the same chunk offset within an upload session are serialized to prevent interleaved writes while permitting disjoint offsets to proceed in parallel.
- **Access control resolution hardening**: Path resolution re-evaluates effective permissions for child paths and prevents explicit deny rules from being bypassed by parent permissions during WebDAV PROPFIND directory walks.

## Frontend reliability

- **SMB settings reconfirmation**: Modifying SMB access switches prompts for account password reconfirmation and synchronizes UI switch state on failure.
- **Network timeout and response validation**: API requests apply a 30-second default timeout signal and validate JSON parsing on successful responses.
- **Setup flow error recovery**: Decoupled administrator account creation from immediate login so transient authentication failures do not misreport account creation as failed.
- **Settings modal error visibility**: Surfaced descriptive error messages when revoking or wiping app passwords and when changing account passwords under rate limits.

## Performance and architectural improvements

- **WebDAV PROPFIND favorites caching**: Favorites are cached within the request context to eliminate repeated database queries during directory listings.
- **Search index build mutual exclusion**: Concurrent search index builds are rejected with conflict status to prevent index corruption.
