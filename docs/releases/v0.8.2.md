# Release v0.8.2

This release resolves security vulnerabilities across authentication, single-sign-on unlinking, two-factor enrollment, WebDAV trash isolation, SMB publication, and upload preconditions, and updates backend and frontend dependencies to their latest versions.

## Fixes

- **OIDC unlinking**: Removed the hardcoded fallback password on administrative unlinking. Self-service unlinking now strictly requires password reconfirmation, preventing account takeover from existing sessions.
- **Two-factor authentication**: Candidate verification codes during TOTP re-enrollment are verified before writing to the database, ensuring an invalid code never removes an existing factor.
- **WebDAV trash authorization**: WebDAV trash operations now enforce the credential's allowed shares and permission mask, blocking unauthorized purge operations from restricted app passwords.
- **App password expiry**: Added range limits on expiration days to prevent 64-bit integer overflow into perpetual credentials.
- **SMB group grants**: Group-level allow grants and deny rules now expand to all constituent member accounts during Samba configuration publishing.
- **Upload preconditions**: Atomic If-Match validation is evaluated at finalization publish time to prevent race conditions during concurrent writes.
- **Dependency updates**: Upgraded fasthttp to v1.73.0 (clearing GO-2026-4950), golang.org/x/crypto to v0.56.0, and updated frontend dependencies to their latest compatible versions.
