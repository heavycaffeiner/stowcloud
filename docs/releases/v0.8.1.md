# Release v0.8.1

This release repairs the checks and clients that still addressed file bytes by path after v0.8.0 moved content reads onto sealed row references.

## Fixes

- **Editor content reference**: The mock backend composed a row's content reference from the entry's leaf name, so opening a file below the root resolved to a path that does not exist and the editor rendered its error state instead of the text view.
- **Container smoke test**: The compose smoke check read uploaded bytes through `files/read?path=`, which the sealed-reference route answers with `404`. It now takes the reference the listing carries.
- **Podman integration script**: The image and video content checks take the same reference rather than a path.
- **Verification gates**: The route-count drift test read a planning document that is no longer tracked in the repository, so it failed on every clean checkout. The phase-document gate now reports itself skipped when those documents are absent instead of passing on an empty loop.
- **Log chart audit**: The admin log graph draws each bar segment as a percentage of a record count, which no 4px grid can hold. The plot carries a documented waiver, and the numbers table's disclosure control is block-level so its inset is even.
