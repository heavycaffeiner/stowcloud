# Release v0.7.0

This release implements a Nextcloud client compatibility layer for desktop and mobile synchronization clients, and adds image and video preview support to the WebUI.

## What changed

**Nextcloud client compatibility layer.** The compatibility surface now answers requests from official Nextcloud Android, iOS, and desktop synchronization clients:
- OCS share management: full CRUD support for user shares, group shares, and public links under `/ocs/v1.php/` and `/ocs/v2.php/`.
- File search provider: integrates with the engine search service to return ranked file results with cursor-based pagination.
- WebDAV trashbin: exposes trash listings as multistatus XML under `/remote.php/dav/trashbin/trash/`.
- Direct media streaming: generates signed single-use claims for direct media playback.
- Targeted app password revocation: credential deletion routes identify and revoke the exact credential that authenticated the request.
- Extended capabilities: advertises supported features including direct editing, user status, and sharing endpoints.

**WebUI media preview.** The file browser preview dialog renders images and videos without downloading:
- Full-screen video player with playback controls, keyboard navigation, and responsive scaling.
- Automatic fallback to the download card when media cannot be rendered or decoded.
- Clean error recovery that clears failed media URLs to prevent stranded player states.

## Upgrading

Pull the updated container images:

```
ghcr.io/heavycaffeiner/stowcloud:0.7.0
ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.7.0
```

Compose stacks using `:stable` or `:latest` can pull and restart directly.
