# Release v0.19.0

This release fixes a file browser bug that made large folders unusable past the first screenful, repairs the public share listing layout, and moves the remaining native dropdowns onto the Material component set.

## File browser

Scrolling a folder larger than one screen now renders the rows it reaches. The list and grid views measured their scroll offset against the window, which never scrolls in this layout: the shell's main region owns the scrollbar. Every measurement therefore read zero, so the rendered window stayed pinned to its first slice and everything below it was blank no matter how far the wheel turned. How many rows appeared before the blank space started depended on the viewport height, which is why the cut-off moved with the window size. Both views now own their scrolling, and the rendered window follows the scrollbar.

The public share page listing no longer breaks apart. Each row declared three grid columns and rendered four cells for a file, so the download control wrapped onto a second line and the icon column stretched across half the row, pushing the name and size to the far edge. Rows now lay out with the icon first, the name taking the free space, and the size and download control at the end.

## Web interface

Every dropdown in the interface is now a Material select. The shared select component, the emergency repair screen's section picker, and the group member picker each still used the browser's native control, which ignores the app's theme and renders its own popup.

## Documentation

The README screenshots are retaken against this release and ship in light and dark variants, so they follow the reader's own colour scheme.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.19.0`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.19.0`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
