# Release v0.15.0

This release expands and redesigns the browser text editor.

## Text editor

The editor now recognizes a broad set of source code, configuration, data, markup, documentation, and shell script extensions. Known text files can be opened from both the file action menu and the preview dialog, while binary formats are kept out of the text editing path.

CodeMirror selects its language mode from the filename and applies syntax highlighting that follows the active Stowcloud color theme. The current language is shown beside the filename, with a plain-text fallback when no language mode is available.

The editor toolbar now separates the filename, language, size, unsaved state, and read-only state. The editing surface has clearer gutters, active-line and selection states, a visible focus boundary, and responsive desktop and mobile layouts.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.15.0`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.15.0`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
