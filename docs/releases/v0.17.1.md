# Release v0.17.1

This release fixes large file uploads from Nextcloud clients.

## Nextcloud compatibility

Direct WebDAV uploads now stream request bodies to disk when they exceed the server's buffered-body threshold. Large files are no longer rejected with `413 Payload Too Large` before the Nextcloud compatibility handler can receive them.

The existing route-specific limits for JSON, XML, and public upload requests remain enforced.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.17.1`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.17.1`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
