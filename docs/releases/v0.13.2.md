# Release v0.13.2

This release updates the web interface and fixes folder activation and narrow-screen layouts.

## File navigation

A single click selects a folder without opening it because another folder was clicked immediately before it. Double-click and double-tap activation require consecutive interactions with the same path in both list and grid views.

Long breadcrumb labels truncate within the available width. Hidden ancestors remain available through the breadcrumb menu. Global search stays in the application navigation.

The mobile folder selector stays open when entered from Menu instead of being dismissed by a stale dialog close event.

## Preview and search dialogs

File previews use a rounded panel with space around every edge, matching surface colors, and a contained toolbar. Previous and next controls no longer reduce the width available to file content.

Desktop search loads its own styles without requiring a visit to another page first. Its input, filters, and results appear inside an inset, rounded dialog.

## Settings and mobile spacing

Settings and Admin share page widths, card spacing, and rounded section buttons with visible keyboard focus. Their backgrounds remain continuous with the application shell.

Upload settings and log filters now use content-sized inputs when stacked on narrow screens. The horizontal layout's 180-pixel field basis no longer becomes empty vertical space between controls.

## Frontend runtime

The web interface now uses React, TanStack Query, and MDUI. File browsing, account settings, administrator settings, and public pages use the rebuilt interface.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.13.2`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.13.2`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
