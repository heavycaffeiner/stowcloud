# Release v0.13.3

This release fixes browser preferences, long data lists, administrator rows, and log charts.

## Browser preferences

Theme, language, and upload concurrency controls now select an option and restore it after a reload. Clicking the selected option no longer clears the preference. Stored concurrency values from 1 through 16 remain visible even when they are not one of the common presets.

View mode, density, sort order, and details visibility retain their existing browser storage behavior. Upload chunk-size overrides now cross the page and upload-worker boundary. Adaptive chunk reductions are persisted by the page instead of relying on storage that is unavailable inside a dedicated worker.

## Long data lists

Long file, folder, search, recent, trash, link, account, administrator, transfer, job, and log lists render only the visible rows plus a small overscan. Variable-height rows are measured, focused and edited rows remain mounted, keyboard traversal reaches offscreen records, and hidden dialogs do not initialize a virtual window until they become visible.

On narrow screens, the file list and grid scroll inside the available content area. Search, breadcrumbs, and the toolbar stay in place. The final row keeps space above the bottom navigation and selection controls.

## Administrator interface

User status switches, quota values, and action buttons align in fixed columns without truncating quota text. The log timeline now renders nonzero buckets with proportional segment heights and the same colors and patterns used by its legend.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.13.3`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.13.3`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
