# Release v0.18.1

This release makes a small web interface polish pass and aligns the sidebar's New button with the navigation items.

## Web interface

The sidebar New button now shares the navigation items' horizontal inset and icon-to-label spacing. Its compact form uses the same corner radius as the other compact navigation controls.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.18.1`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.18.1`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
