# Release v0.15.1

This release fixes the container healthcheck after application hosts are configured and shortens the global search label.

## Container healthcheck

The main container now publishes the live listener address and configured application host to its health probe snapshot. Changes to either value refresh that snapshot immediately.

The healthcheck reads the snapshot file instead of treating the data directory as the file. A deployment whose application host does not include the loopback address now remains healthy because the probe sends the configured host through the request boundary.

## Interface and deployment

The global search control now uses the concise label `Search` in English and `검색` in Korean. The README screenshots show the current label in both light and dark themes.

The default Compose file is now `compose.yml`. The normal `docker compose up -d` command discovers it automatically. Commands that explicitly used `-f docker-compose.yml` must use `-f compose.yml` instead.

The README quick start sections now identify the required environment and the Compose file used by the startup command.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.15.1`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.15.1`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
