# Release v0.16.0

This release restores recurring server maintenance, stores the search index at the documented hidden path, and removes cancelled upload parts immediately.

## Search indexing

The search index now lives in `.scindex` under the Stowcloud data directory. Existing indexes stored in the former `index` directory move to the new name automatically when indexing is enabled.

The server now starts its declared periodic tasks after startup preflight and runs each task immediately before waiting for its normal interval. Search builds continue to run as tracked background jobs.

Completed index builds now leave the web job progress bar in a determinate finished state instead of continuing to animate.

## Upload cleanup

Cancelling an upload now waits for admitted writers to drain, removes the `.scpart` file and private spool data, and deletes the session row. If immediate cleanup fails, the aborted row remains available for a later DELETE request or periodic sweep.

The upload sweep now starts with the other recurring maintenance tasks, so expired sessions and orphaned upload parts are checked at server startup and every five minutes afterward.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.16.0`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.16.0`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
