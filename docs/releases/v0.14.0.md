# Release v0.14.0

This release keeps long file and folder names inside their rows and refreshes the README interface gallery.

## File browser

Long names in list view now remain on one line and truncate with an ellipsis. The visible suffix is retained so extensions and distinguishing endings stay readable. Rows keep their fixed height on narrow screens and no longer overlap adjacent names, checkboxes, or size values.

Grid view retains the same truncation behavior.

## Documentation

The English and Korean README galleries now show the current interface for browsing, setup, folder navigation, search, sharing, folder grants, text editing, and trash.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.14.0`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.14.0`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
