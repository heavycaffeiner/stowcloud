# Release v0.18.0

This release delivers a comprehensive web interface rework, streamlines the search overlay with category filter pills, and repairs Nextcloud client uploads encountering `413 Request Entity Too Large` during adaptive chunking.

## Web interface rework

The web application now features a full-width header bar, a collapsible sidebar with compact icon mode, a dedicated "+ New" action button, and a storage usage indicator card.

File browsing includes dropdown filter pills for file types and modification dates, category-aware file icons, contextual action menus per row, and a centered floating action bar for active selections.

File details inspection provides a hero preview card with large category badges, primary download actions, and organized metadata properties.

## Intuitive search overlay

The search overlay has been redesigned into an uncluttered modal dialog. Multi-row forms have been replaced with a streamlined query bar, single-tap horizontal category filter pills (All, Files, Folders, Documents, Images, Videos, Audio, Archives, Code), folder scope context, and relevance or property sorting.

## Nextcloud compatibility

Nextcloud chunked uploads now support adaptive chunk sizing without premature length restrictions. Sessions opened without a pre-declared total length no longer reject larger subsequent chunks with `413 Request Entity Too Large`.

## Container images

The core and SMB images are published for Linux AMD64 and ARM64:

- `ghcr.io/heavycaffeiner/stowcloud:0.18.0`
- `ghcr.io/heavycaffeiner/stowcloud-smb-daemon:0.18.0`

The `stable` and `latest` tags point to this release. Existing Compose deployments using those tags can update with `docker compose pull` followed by `docker compose up -d`.
